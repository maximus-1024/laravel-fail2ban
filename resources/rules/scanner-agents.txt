# 扫描器特征（scanner-agent）的浏览器标识清单。不看状态码，每次请求都算。
#
# 每行一个字面量（不是正则），不分大小写，在浏览器标识里「按词」查找：
# 条目首尾是字母或数字时，要求它前后不紧挨着字母或数字（"nmap" 不会命中 "sitenmapx"）。
#
# 条目数：76。核对日期：2026-11-07。
#
# 出处：OWASP CRS rules/scanners-user-agents.data（规则 913100 用）
#   https://raw.githubusercontent.com/coreruleset/coreruleset/main/rules/scanners-user-agents.data
#   2026-11-07 重新下载逐条比对：本清单 76 条与 CRS 现行版本一致，CRS 多出的只有下面写明去掉的 4 条。CRS 维护者在文件头说明这份清单是手工挑选的、
#   只收「几乎肯定不受欢迎」的扫描器，正是我们要的口径。
# 交叉对照：CrowdSec http-bad-user-agent 的 bad_user_agents.regex.txt（同日在线打开）。
#   那份清单有六百多条，混着 SEO 爬虫和 PyCurl、lwp-request、HTTP::Lite、Typhoeus、
#   Mojolicious 这类通用库，以及 Bolt、Buddy、Collector、Dispatch 这类普通单词，
#   误伤面太大，整体不取；其中的安全扫描器（Nikto、Nuclei、Sqlmap、Nmap、Masscan、
#   OpenVAS、Nessus、Acunetix、gobuster、Dirbuster、Havij、Fimap 等）CRS 都已包含。
#
# 从 CRS 清单里去掉的：
#   Mozilla/6.0   （CRS 自己也注明是「技术上合法」的标识，拿不准）
#   hexometer     （网站监控服务，运维或商户可能拿它做可用性监控）
#   sitelockspider（网站安全托管服务的巡检爬虫，站长主动订阅的服务）
#   securityagent （查不到确切来源，拿不准）
#
# 2026-11-07 删掉的「补充」一组（3 条，核对不了出处）：
#   ffuf     ：ffuf 的默认标识是 "Fuzz Faster U Fool v<版本>"（源码 pkg/runner/simple.go），
#              已由 CRS 的 "fuzz faster" 覆盖；"ffuf" 这个词不是它的默认标识。
#   dirsearch：默认标识是一个普通的 Chrome 标识（源码 lib/core/settings.py），不带 dirsearch 字样。
#   jaeles   ：每次随机取一个浏览器标识（源码 sender/sender.go），不带 jaeles 字样。
#
# 永远不收：curl、Wget、Guzzle、okhttp、python-requests、python-httpx、aiohttp、
#   Go-http-client、Java、Apache-HttpClient、axios、node-fetch、undici、PostmanRuntime、
#   libcurl、PHP 等通用库与工具。商户服务器就是用它们调接口的。空标识也不算。
